🧠 What is a Lookup Function?

👉 It helps you search a value in a table and return a related value.

🔥 1. VLOOKUP (Most Asked)

✅ Syntax

VLOOKUP(lookup_value, table_array, col_index, [range_lookup])

💡 Example
ID	Name	Salary
101	Ram	20000
102	Shyam	30000

=VLOOKUP(101, A2:C3, 2, FALSE)

👉 Output: Ram

⚠️ Limitations

Only searches left → right
Breaks if column order changes

🚀 2. HLOOKUP

👉 Works horizontally

=HLOOKUP(value, table, row_number, FALSE)


⭐ 3. XLOOKUP (BEST 🔥)

👉 Modern replacement of VLOOKUP

✅ Syntax

=XLOOKUP(lookup_value, lookup_array, return_array)

💡 Example

=XLOOKUP(101, A2:A3, B2:B3)

👉 Output: Ram

🔥 Why XLOOKUP is BEST?

✔ Works left & right
✔ No column index needed
✔ Handles errors easily

⚡ 4. INDEX + MATCH (INTERVIEW FAVORITE)

✅ Syntax

=INDEX(return_range, MATCH(lookup_value, lookup_range, 0))

 Example

=INDEX(B2:B3, MATCH(101, A2:A3, 0))

👉 Output: Ram

🔥 Why Important?

👉 More flexible than VLOOKUP
👉 Works in any direction

🆚 Quick Comparison
Function	Direction	Flexibility	Recommended
VLOOKUP	Left →   Right         	  Low	         ❌ Old
HLOOKUP	Top →     Down	          Low	         ❌ Rare
XLOOKUP	          Any	          High	         ✅ Best
INDEX+MATCH       Any	          Very High	 ✅ Interview


🎯 When to Use What?
Beginner → VLOOKUP
Real work → XLOOKUP
Interview → INDEX + MATCH
